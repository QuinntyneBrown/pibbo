Overview

Every round starts with Pibbo speaking a prompt. The bubble shows the same words, a picture of what is asked, and the hear button, so the instruction works with the sound off and for a child who cannot yet read.

Anatomy

  1. Pibbo72px mascot
  2. Picture48px icon of what is asked
  3. Prompt20px, 24px from 40rem
  4. Hear button60px
