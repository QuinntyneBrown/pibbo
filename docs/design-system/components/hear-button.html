Hear button

The round speaker button inside the speech bubble: touching it plays what Pibbo said again.

Overview

Every prompt Pibbo speaks can be heard again. The hear button sits at the end of the speech bubble and takes the subject's tint. It is never the only way to get the instruction: the words are always shown too.

Anatomy

  1. Speaker icon20px stroke, subject colour
  2. Disc60px circle in the subject tint

Sizes

One size: 60 × 60px, the smallest target a child touches.

Theming

Reads --color-count-soft / --color-count-fg (or the read pair). In dark the tint deepens and the icon lightens.

Accessibility

Role and pattern

Native <button>.

Keyboard

KeyAction
Enter / SpacePlays the recording again

Focus

Shared 4px ring.

Labelling

aria-label="Hear it again"; the icon is aria-hidden.

Contrast

Icon on Count tint · light

Icon on Read tint · light

Motion

None. The recording plays; nothing moves.

Touch

60 × 60px; repeated taps restart the recording rather than overlap it.

Content

  • Name it for the child's goal: "Hear it again".
  • The recording it plays is the same words shown in the bubble.
