Theming

Path sits on the subject tint; nodes use art white and success.

Accessibility

Role and pattern

An ordered list with aria-current="step".

Keyboard

KeyAction
TabMoves to the current node, then each done node
Enter / SpacePlays the current game, or plays a done game again

Focus

The current node and done nodes take focus; a later node is disabled and is skipped.

Labelling

Step names.

Contrast

Name on tint · light
Name on tint · dark
Number · light
Number · dark

Motion

None.

Touch

Every node is at least 80 px (112 px now); done and current nodes are one-touch targets, later nodes take no touch. The current step is marked by shape (larger, with a play mark) and colour, never colour alone (journey 22).
