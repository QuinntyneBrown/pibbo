Button (Chunky)

Chunky is Pibbo's one button: big, rounded, with a press edge that sinks when it is touched.

WCAG 2.2 AAStatus: stableBlock .chunky

Overview

Use Chunky for every action a child or grown-up takes: Check, Next, Start, Leave. The colour says which subject the action belongs to, never how important it is; a screen still asks one thing of the child, so it has one coloured Chunky. Use the hear button to replay what Pibbo said and a numeral or tile for an answer.

  • Count (blue) and Read (pink) carry the activity's main action: Check.
  • Success (green) appears only after a right answer: Next.
  • Reward (lilac) starts something earned; ink is for grown-up actions.
  • White is the quiet button: Leave, Home, Replay. Usually icon-only.

Anatomy

  1. LabelFredoka 20px semibold, one verb
  2. Icon (optional)24px stroke icon, aria-hidden
  3. Body and press edge56px tall, 20px radius, 5px edge in the --depth colour

Responsive

Theming

Chunky reads the subject roles --color-count-strong, --color-read-strong, --color-success-strong, --color-reward, and sets --depth for the press edge. The strong subject colours stay the same in dark so the button keeps its identity; only white Chunky follows the surface.

Accessibility

Role and pattern

Native <button>, or <a> when it navigates (Leave, Home). Follows the WAI-ARIA Button pattern.

Keyboard

KeyAction
TabMoves focus to the button
Enter / SpaceActivates

Focus

A 4px outline in --color-focus-ring, 3px outside the body, visible on every subject colour.

Labelling

The visible label is the name. Icon-only buttons carry aria-label ("Leave game", "Replay").

Motion

The press sinks 4px in 120ms and stops. Reduced motion removes the travel; the colour change remains.

Touch

56px tall, icon buttons 60 × 60px, at least 16px from the next target. One tap; no long press.

Content

  • One verb, sentence case: Check, Next, Start, Try again.
  • Spoken as well as shown when Pibbo asks the child to press it.
  • No exclamation marks on buttons; praise belongs in the answer bar.
