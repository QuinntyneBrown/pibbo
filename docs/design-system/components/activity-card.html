Overview

Activity cards fill the grid under the group switch, at most six per screen. Each is one link; the whole card is the target.

Offline, never opened

Offline (L2-033, ADR 0031), an activity that was never opened greys after a touch and draws the no-network symbol; it does not open. Grey is never the only sign: the symbol is drawn and the picture is named “needs the internet” to a screen reader. The state is aria-disabled="true" on the button, which stays focusable. Source: home/offline.
