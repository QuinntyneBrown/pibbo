Overview

Activities are a fixed frame (the shell) that fills the viewport; Home is a centred grid.

Page templates

  • Activity: shell, 100dvh, no scroll.
  • Home: wordmark, group switch, activity grid capped at --content-max.
  • Grown-up: narrow column at --content-narrow, away from the child's path.

Usage

  • Media queries use the rem values (40, 48, 64rem); custom properties cannot be used in @media.
  • More room, not more things.
