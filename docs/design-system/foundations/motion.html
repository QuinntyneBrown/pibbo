Motion

Motion shows what happened and then stops.

WCAG 2.2 AALight and dark
  • Overview
  • Durations
  • Reduced motion
  • Usage
  • Tokens

Overview

The press (120ms), colour changes (150ms), progress (300ms), and Pibbo lighting each toy as it counts (500ms per number). Nothing idles or loops.

Durations

Reduced motion

Under prefers-reduced-motion every duration token is 0; the activity still makes sense because the result (a badge, a fill) is shown.

Usage

  • No flashing, no shaking a wrong answer.
  • Ease out (--ease-out-quint) for the press.

Tokens

Every motion token in tokens/tokens.css, resolved live for each theme.
