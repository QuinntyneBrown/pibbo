Overview

:root is light. [data-theme="dark"] forces dark; otherwise prefers-color-scheme: dark applies unless the page sets data-theme="light". Each theme sets color-scheme.

Token tiers

TierExampleThemed?

Nested themes

Aliases and derived tokens are declared on :root, [data-theme], so a dark wrapper inside a light page resolves correctly, as the side-by-side examples on every page show.

Adding a theme

  • Add a [data-theme="name"] block overriding semantic roles only.
  • Add its pairs to contrast-pairs.json and run check_contrast.py.
  • Regenerate tokens.json with tokens_to_json.py.

tokens.json

tokens/tokens.json is DTCG: $type, $value, aliases as {palette.purple.500}, dark under $extensions. The Angular app's _tokens.scss carries the same values.
